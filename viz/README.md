# CRDT Benchmarks Visualization

Interactive visualization tool for analyzing CRDT benchmark results.

## Getting Started

1. Ensure your benchmark results are in `becnhmarks/results.json` in the correct format

2. Run the visualization tool:

```bash
npm run dev
```

3. Open your browser and navigate to http://localhost:3000

### Features

- Relative performance ratios displayed in parentheses
- Color-coded performance indicators (green for better performance, red for slower)
- Sortable results by clicking on benchmark names
- Framework selection for targeted comparisons
